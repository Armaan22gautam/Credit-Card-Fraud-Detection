PCA Features – Key Insight V1–V28
🔒
Anonymized by PCA
Features V1–V28 are the result of PCA dimensionality reduction applied to the original data to protect cardholder privacy.
⚖️
SMOTE Resampling
The training set had 227,451 normal vs 394 fraud cases. SMOTE was applied to create 227,451 synthetic fraud samples for balanced training.
📏
StandardScaler
The Amount and Time features were scaled separately using StandardScaler to prevent feature dominance during model training.
🎯
Stratified Split
An 80/20 stratified train-test split preserves the class ratio in both sets, ensuring unbiased evaluation of rare fraud cases.
